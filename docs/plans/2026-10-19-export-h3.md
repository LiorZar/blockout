# Export basics: H3 Max profile + a prompt that maps proxies and describes the action

Lane `export-h3`. Brief: `.maestro/handoffs/worker-export-h3.md`.

## Goal

Export a shot for **MiniMax H3 Max 3D to Video** that the model accepts (≤ 15 s, ≤ 50 MB) and a `prompt.txt` (every profile) that says what each grey shape is, what happens in time order, and what the camera does.

## My calls

- **Profile** `minimax-h3-max`: 1080P (`exportWidth: 1920`), 24 fps, aspects 16:9 / 9:16 / 1:1 (MiniMax's usual set; CLAUDE.md doesn't list them), `recommendedDuration: 10`, `refModes: ['referenceVideo', 'firstFrame']`.
- **New optional profile fields** (no upstream profile changes): `maxFileMB` (H3: 50), `maxPromptChars` (H3: 2000), `promptStyle: 'previs'` (the prompt ends with the profile's own `adherenceClause` instead of the generic motion-reference directive, per `docs/generator-profiles.md` "behind a profile field, not an id check").
- **Size cap**: capped CRF. libx264 keeps `-crf 18` and adds `-maxrate` / `-bufsize` (2 s buffer) only when the profile has `maxFileMB`: `maxKbps = maxFileMB · 8000 · 0.9 / (duration + 2)`, so even worst-case content stays under the cap. Other profiles' encodes are untouched. Needs one optional field through `exportBegin` (`exporter.ts` → `preload/index.ts` → `main/index.ts`).
- **Limits surfaced**: one pure `profileWarnings(profile, shot)` (duration over `maxDuration`, aspect the model doesn't list) feeds both the Deliver panel (replaces upstream's single over-cap chip with the list) and `export_shot` (new `warnings` field). Export is not refused.
- **Prompt layout** (all profiles): proxy map → action → camera → upstream look line + setting → directive. The proxy map replaces upstream's `Subjects:` line when there is something to map; each new section appears only when it has content, so upstream's prompt tests hold. Budget = `maxPromptChars ?? 1500`; the proxy map is kept first, then camera, then action lines while they fit, ending with "The action continues as in the reference video." when trimmed.
- **Proxy map** names colours (label colour → palette name, else nearest hue word, else grey) and shapes (figure / mannequin / box on wheels / …); the label text goes in parentheses as the name the action uses, since labels are usually not burned into the clip.
- **Action**: Fight Director fights are re-solved (pure, deterministic) for their per-impact outcome (absorb / stagger / knockdown / KO); applied motions are recognised by matching the marks' joints to motion presets (also mirrored); walks / runs / drives are segments between marks, with screen direction from the camera (`ShotEvaluator`); two runners on the same line read as a chase.
- **Camera**: live shot words (collapsed, in order), else the move measured from the evaluated camera (forward / back / left / right / up / down, pan, lens change, written without "zoom"), rig name, aim lock, car mount.
