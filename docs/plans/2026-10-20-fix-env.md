# fix-env: a place behind the action, local-time export stamps

Lane `fix-env`, round 4 (2026-10-20). BACKLOG bugs: "The default day lighting renders a flat grey void behind the action" and "Export folder stamps are UTC".

## Goal

Every lighting preset renders a ground that runs out to a visible horizon under a graded sky (or, indoors, a dim room surround), so a video model reads a floor plane, an eye line and scale instead of a flat field. Exports keep zero editor chrome, depth / normal passes stay valid, renders stay deterministic. Export stamps use local time.

## Cause

`SceneManager` sets `scene.background` to one flat colour (`day` = `0x394048`, exported as RGB 57,64,72), and its only ground is a transparent `ShadowMaterial` plane, so the floor and the sky are the same colour with no horizon. The export renderer has no tone mapping, so the `*Sky` presets' physical sky clips to white.

## My calls

- **Look:** a backdrop dome (vertical gradient, zenith → horizon band → ground below the horizon) plus a lit ground plane at y = −0.01 m that receives shadows, with a faint 1 m checker for scale and perspective (filtered with `fwidth`, so no moiré or shimmer) that hazes into the horizon colour with distance. The horizon line stays crisp, because the hazed ground is a little darker than the sky's horizon band.
- **Per preset:** `day`: blue-grey sky, mid-grey ground. `goldenHour`: dusk blue to warm peach, warm ground. `night`: navy sky with a faint horizon glow, dark ground that is still distinct from it. `interiorWarm` / `interiorCool` / `club`: a dark room surround (no sky), and a floor that hazes into it within ~25–40 m, so it reads as a dim hall. `*Sky` presets: keep the physical `Sky`, add the same ground, scale the sky's radiance (`SKY_EXPOSURE` 0.22, tuned by eye) and tone-map it in exports the way the viewport does (ACES, ×1.45), so it is no longer a white void. Ground albedos were tuned on rendered frames: goldenHour uses a blue-grey albedo (`0x485870`) so the orange sun doesn't swallow the red and orange cast, and night uses a lighter one (`0x9aa2b6`) so the legs read against the ground.
- **Passes:** the dome shows only in the clean pass (like `Sky`). The ground stays in depth / normal passes, as the old shadow plane already did, so the floor gradient in depth is unchanged.
- **Fog:** the user fog's colour becomes the horizon colour (it used to be the void colour).
- The old transparent shadow-catcher plane is hidden, because the new ground catches the shadows (otherwise they would print twice).
- The code is a new file, `src/renderer/viewport/environment.ts`, with small hooks in `SceneManager` (constructor, `applyEnvironment`, `renderFrameAt`).
- **Stamps:** `exportStamp(date)` in a new `src/renderer/export/stamp.ts` gives local `YYYY-MM-DD-HH-mm-ss`. The four `toISOString()` sites call it.
