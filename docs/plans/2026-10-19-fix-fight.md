# fix-fight (round 3): fights stay exact, one fight system, props, bodies over MCP

Goal: close GAPS.md gaps 2, 3, 8 and 9 so a staged fight survives shot edits, agents can't pick the fight where blows miss, fights don't run through set props, and Clara can choose the fighters' bodies.

## My calls

- **Re-solve scope (gap 2):** "the shot's fights" are the scene's fights whose two fighters both have fight marks (`lockFacing`) in the shot's blocking take. They are re-solved inside the same `mutate` as the fps/duration edit (one undo step). The beats stay in the `FightDoc`, so a beat dropped by a shorter shot comes back when the shot is lengthened.
- **Coverage on re-solve:** the camera is re-written only when every camera mark is a shot-words mark on the fight's own fighters (the coverage the fight wrote). A camera the user changed is left alone.
- **Two fight systems (gap 3):** no upstream test depends on the old two-person fight output (the only upstream test, `control-tools.spec.ts` "choreograph_entities", checks `choreographed: 2`). So a 2-person `kind: 'fight'` (`spawn_choreography`, `choreograph_entities`) and a 2-performer Sequences fight go through `stageFight` with a seeded random script (style → script pool, ending `finish` → KO). Bigger crowds keep the upstream crowd brawl; the three tool descriptions say so and point to `stage_fight`; the Sequences panel shows a hint pointing to the Fight Director.
- **Props (gap 8):** obstacles are oriented footprint boxes taken from the built geometry of every static non-person entity (kits included: the gym's benches and rack posts live inside `env.gym`), in a body-height band (0.2–1.7 m). The solver stops a stagger, a guarded push-back and a knockdown slide (incl. the fallen body's length) at the first obstacle, and warns whenever a solved root path crosses one. A fight that spawns its own fighters moves its start (up to 3 m) to the nearest spot where the solved paths are clear, and says so in the report.
- **Bodies over MCP (gap 9):** `stage_fight` takes `assets: [A, B]` (person asset ids) and `labels: [A, B]`; both refuse to combine with `fighterIds` (existing people keep their bodies).
